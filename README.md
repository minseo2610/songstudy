## 팀 공통 데이터

2026년 11월의 5과목·17개 할 일을 [공통 JSON](./common/00_mystudy_data.json)에 정리했습니다.
각 페이지는 [공통 데이터 모듈](./common/00_mystudy_store.js)의 `MyStudy` API를 사용합니다.
데이터 구조, 페이지 연결 방법, 주간 조회 예제는 [공통 데이터 사용 안내](./common/README.md)를 참고하세요.

## B 담당 화면

- [주간 플래너](./mystudy/weekly.html): 주 이동, 미니 달력, 과목 필터, 완료 체크, 마감 미정 목록, 주간 메모. 날짜 칸을 선택하면 추가 버튼, 할 일에 마우스를 올리거나 키보드로 초점을 옮기면 수정·삭제 버튼이 나타납니다. 터치·클릭으로 선택해도 열 수 있으며 삭제는 알림의 ‘되돌리기’로 복원할 수 있습니다. 오늘만 진한 핑크로 표시하며 이번주 할 일은 `(완료 수/전체 수)`로 표시합니다.
- [학습 타이머](./mystudy/timer.html): 과목·할 일 선택, 스톱워치, 집중 타이머(25분·50분·직접 설정), 일시정지·재개, 오늘의 학습 기록.

프로젝트 루트를 제공하는 정적 HTTP 서버에서 두 HTML을 엽니다. 타이머는 실제 시각 차이로 경과 시간을 계산하며, 새로고침 뒤에도 진행 상태를 복원합니다. 학습 기록은 `myStudy.studySessions`, 측정 중 상태는 `myStudy.timerState`에 저장합니다. 오늘의 합계는 학습 종료일을 기준으로 계산합니다.

공통 데이터와 타이머 시간 계산 검증: `node --test tests/common-data.test.cjs tests/timer.test.cjs`.
